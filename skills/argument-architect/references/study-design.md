# 研究设计适配指引

这些是可选择的审阅问题，不是覆盖所有领域的报告规范，也不是对任何项目均强制的清单。根据实际设计、目标主张和该领域适用的官方规范调整。缺少能力时记录 unknown 和所需专门审阅。

| 设计/论证任务 | 需要区分的证据与推理 | 典型保留边界 |
|---|---|---|
| 算法/方法比较 | 基线、数据划分、调参/算力条件、评价指标、方差与失效场景；优势是否仅来自条件差异 | 特定任务/数据/资源范围；单次结果不等于稳定全面优势 |
| 机制解释 | 观察预测、干预、替代机制、能区分解释的结果 | 与机制一致与排除其他机制分开表述 |
| 观察研究 | 抽样、测量、混杂、缺失、选择偏差及模型假设 | 关联和因果分开；未建立识别条件时限制因果措辞 |
| 干预/随机试验 | 分配、对照、分析人群、结局定义、失访和不确定性 | 效应适用人群和实施条件；探索性结果与预设结局分开 |
| 理论/证明 | 定义、假设、引理、推导依赖、边界情况 | 定理结论不越过假设；数值例子不能替代证明 |
| 质性研究 | 材料、抽样处境、编码过程、解释与反例的联系 | 解释的情境和研究者立场；避免无依据的总体频率主张 |
| 综述/综合 | 检索范围、纳入排除、来源质量、证据差异 | 有限范围的综合与穷尽性/因果结论分开 |

context 的 study_design 层记录本项目采用了什么、对当前关键主张哪些要求适用、哪些缺失。不能仅凭“生物学”或“机器学习”等领域标签推定研究设计。

同一项目可组合设计，例如比较实验支持性能主张，消融支持局部解释，观察数据只支持关联；分别建立 claim 和 warrant，不把最强的证据等级传播给所有结论。
