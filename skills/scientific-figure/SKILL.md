# 科研绘图

以“科学语义 → 读者判断 → 视觉论证 → 可复现渲染 → 科学核验与读图”连接绘图和论文。先查现有源文件与绘图后端，能局部改就局部改。

先读 [故事、图表与风格协作](references/story-and-style.md)：先确认讲什么，再选择能支撑判断的图表，最后优化美观。复杂任务与用户比较不同叙事；不要把尚未选定的代理建议写成用户决定。参考库按具体图件观察状态与三个索引检索，不按期刊名称直接套版。

作者还不知道主线或图种时，从材料中的现象、对照、困惑和读者需要完成的判断启动；先由代理提出有依据的故事与构图候选，帮助作者纠正和收敛。不要把“告诉我你想画什么”作为必需入口。跨一批论文的材料归纳及可运行讨论交接见 `$research-harness` 的[故事共构](../research-harness/references/story-discovery.md)。

## 必要契约

对本次受影响的图/面板明确：

- 具体科学对象及身份、研究问题、证据角色、数据/结构/资产来源；
- 读者需要完成的判断及不可推断项；
- 单位、条件、参照态、样本与不确定性定义；
- 科学关系的类型及依据，面板之间的配对、共享尺度与阅读顺序；
- 必须保持、可以省略、尚不确定的内容，以及图注职责。

来源依据（观察/计算/假设/未知）与表达形式（定量/示意/混合）是两个维度。箭头不能把数据流变成因果，示意曲线不能冒充连续计算结果。不同语义的颜色分别命名：元素、实体、方法、状态和连续场。

## 按任务加载

- **复杂论文的首稿与严格质量判断**：用[首稿视觉决策与盲评](../research-harness/references/first-draft-and-blind-review.md)先比较空间组织不同的候选，再制作；核心维度仍有实质缺陷即需返工，不把“能读懂”记为正式视觉达标。
- **要求复现原图**：读 [原图重建与两条验收线](references/reconstruction.md)，直接并排显示原图与重建并报告差异；卡片和运行通过不能代替视觉复现。
- **新图与参考图**：读 [设计与参考解析](references/design.md)。先做低保真构图，再用任务匹配的参考比较；复杂图比较有结构差别的候选，简单编辑无需重复规划。
- **构图单调、版式不稳或需要归纳参考**：读 [教材原则与适用边界](references/design-principles.md)，从读者任务、拓扑、色彩角色及出版尺寸定位问题；不用期刊名称直接决定布局。
- **统计、表格、化学/三维、方法图、TOC**：读 [领域与后端边界](references/domains.md) 中对应部分。真实结构优先使用结构文件与领域工具，不用生成式纹理替代研究数据。
- **局部修改**：将修改标为纯呈现、影响解释的呈现、数据/分析。声明允许改变和必须保持，保留已接受的修正；只重验受影响层与已有不变量。
- **用户否定成图质量或反复反馈同一缺陷**：按 `$research-harness` 的[反馈到制作动作](../research-harness/references/feedback-to-practice.md)记录失败并改变制作策略，不能只在原稿上反复换色、缩字或增参考。
- **交付**：保留科学规格、视觉规格、数据与真实资产清单、生成程序、对象 ID 对应、适当的可编辑导出、图注和分项验证。外部编辑若不能回写源语义，标记为派生版本。

先验科学与来源，再验读者任务，再验可读性与风格。检查结果分别写 `passed / failed / unknown / not_implemented`，未检查不能并入通过。盲读者仅看图及目标上下文，不给预设答案；同一模型多次回答不算独立专家。

需要可运行项目时用 `$research-harness`；新增 schematic 用于不强制测量数据的流程/机理示意/结构表达/TOC，summary 用于有明确来源数值与不确定性的图表；两条线分别验证。当前还内置配对图、性能表、单/多路径离散能量图、方法图、原始序列图与真实 OVITO 三维结构。新 TOC 与示意图共用场景；以节点锚点生成实际连接，避免语义关系与所画箭头分离。具体接口见 harness 的场景版式参考。独立结构任务用 `$ovito-structure`。项目级 style profile 统一字体、颜色、字重与斜体，并检查实际文本属性。其他图种保留现有领域后端并如实记录覆盖范围。投稿时查看目标期刊当时的官方要求，按图件用途与工具作用配置；不预置“Nature 通用字号”或通用 AI 出版许可。

正式论文成图按目标尺寸核对真实排版和局部几何，不能以能运行的demo结案。表格复现与热图等重编码另列；见 [故事与风格](references/story-and-style.md)。

统一文字角色仍须检查读者归属：引线应明确指向指定点或事件，双向反应箭头的增减物种应能从图内恢复方向；复杂数学对象可设局部公式角色并重新分区。实际失败、经成图复看的修正与适用条件见[原生尺寸迁移](../research-harness/references/native-size-transfer.md)。

目标尺寸须对应本次用途和已知依据，起稿时确定；TOC的浓缩故事不能依靠大画幅中可读的结构拼盘再缩小。自查应反读图中可直接辨认的对象和关系，不能因自己记得预设答案、中心原子可见或文字放大后可读而放行。具体实测失败与处理见 harness 的[制作循环](../research-harness/references/visual-production-cycle.md)。

TOC 是传播用途，示意/定量是表达方式，真实坐标是来源属性；不将它们视为互斥类型。构图候选要改变读者认识推进方式，而不只是换色；每个候选交代强调、弱化和证据缺口。最终采用的规律保留来源及实际迁移成功/失败条件，复用现有故事与参考字段，不另建冲突的科学主状态。

同一故事还需用于学术演示时，共用既有意图、claims 与证据，按口头讲述重组页面；调用 `$ansatz-slide` 制作本地 PPTX。映射和范围见 `$research-harness` 的[跨媒介叙事](../research-harness/references/cross-representation.md)，不把论文图缩小粘贴等同于完成幻灯片设计。

对已出现小字、结构遮挡、能量曲线生硬或宽屏重排失败的复杂图，采用同套 `$research-harness` 的[成图制作循环](../research-harness/references/visual-production-cycle.md)：先改问题层，再实际看当前导出；不靠期刊标签或统一缩字代替重构。
