# 原图复现与新图设计不是同一个验收

用户要求复现时，先辨认要的是原图驱动重建、科学逻辑迁移还是重新设计。原图驱动重建不能用“大意相近的卡片图”替代。原图、重建图、实际差异一起展示；可以按明确面板设范围，不能默默删掉关键物种、控制或步骤再称全图复现。测试通过和参考卡数量都不能证明成品质量。

## 分开两条线

**解释/示意线**包括流程、模型架构、机理示意、结构表达和 TOC。输入可以是文献图文、概念、结构材料和假设，不强制测量数据。核对对象身份、步骤/依赖/反馈、物质与能量流、箭头含义及证据等级。具体机制不得因箭头漂亮而从假设变成已证实；概念势能曲面不应带伪造的测量刻度。

**定量证据线**从真实数字开始：原始测量、公开数值表或有定位的转录均可，但须分清。保留行/样本/单元格、转换、条件、单位和误差定义。重绘某个分量不等于重现整张图；缺少 H₂ 的来源值，就不能由选择性比例猜均值与 SD。示意线与数据线可以在论文中协同，但分别验收。

结构又分：真实坐标重渲染、来源明确的理想模型，以及依据参考图的说明性几何重建。后两者不能声称恢复作者优化结构。TOC 可以完全是概念叙事；不要求真实曲线或固定四块。

## 原图驱动的制作与对照

以实际面板为依据列出对象、文本、拓扑、空间层级和视觉编码。先保留必要内容和相对位置，再解决材质、阴影、线宽、留白及缩小后的辨识度。原图文字应核对图注与正文；来源字体可从 PDF 测量，但图内位图文字不能靠正文的字体推断。

按物理尺寸缩放字号，而不是给所有参考统一套 8 pt：新字号≈原字号×新图宽/原图宽。比较时原图/重建等宽展示、保持各自比例，可打开全尺寸；另给可编辑规格、程序和差异说明。矢量文字与程序着色球体的 SVG 并不等于整图完全矢量。

本次三个原图驱动重建的实际经验：

- Nature Catalysis Fig1a 的叙事依赖分区、并行采样、选择和具体输出对象，四个等大框会丢失它；source-style 重建应保留全部阶段和标签。概念势能面是说明性对象，不需要捏造数据。
- Nature Communications Fig1 的颜色承担不同反应层级，脱附方向必须正确，不能只重现外观。图2的放大线须指向相应空间区域；两种簇投影的31个示意球不代表已恢复三维坐标。
- 同一 Arial 字体存在不等于包含所有 Unicode 下标；实际缺字会破坏化学式。可用显式配置的 MathText 字体写下标，检查真实导出。

这些是当前案例支持的修正，不是顶刊统一风格或普遍审美优胜结论。当前重建的材质、阴影和图标仍有差异，不能把逐项连接检查包装为视觉达标。


## 材质与数据论证的本次修正

三幅重建先在同尺寸原图上打磨，再迁移：球体要有可控的暗部色、亮部色、光源方向与高光宽度；不要仅把纯色乘亮度而丢掉原图的色相变化。块体各面单独设连续渐变，吸附物与支撑面之间使用低透明度接触阴影。阴影服从支撑面和遮挡次序，不给所有对象统一加浮起的投影。焦点椭圆、放大线与局部结构必须指向同一位置。先改这些会改变空间感的项目，再做字距等细节。

这些参数是二维解释性图件的可编辑材质，不替代真实坐标、表面法向或光学计算。程序球体、渐变和阴影以独立栅格层导出；边界、文字和路径保留矢量。`schematic` 对 sphere 的 material 支持 shadow_color/light_color/light/ambient/specular/shininess；rect/ellipse/polygon/path 的 gradient 支持 colors/direction；shadow 用 box/color/alpha/falloff。默认旧场景不改变。参考具体场景的参数，不把一个案例的材质写成所有期刊的默认。

数据图要从一个可回答的问题开始。写明“哪两个条件/群体的比较，如何支持哪一层结论”，再选择几何：原图的柱形对照不能无理由换成数量级点线图；数据集计数只能回答覆盖问题，不能替代性能证据。`summary.mapping.geometry=bar` 保留零基线的竖向柱形与来源误差；默认区间点图用于适合的位置比较。两者都不能补造缺失 SD 或从比例倒推另一产物。

对照图的解释同时写清：改变的因素、保持条件、测量指标、重复层级、零/低于检测限/缺失之间的差别，以及不能排除的解释。控制变量与结果支持“依赖/增强”并不独自证明微观机制。把正文、图注和读者应得出的判断一并检查，而不是只检验 CSV 数字。

迁移时先冻结本次技能与渲染代码，再以新论文的原图/图注/Source Data 建立新项目；首次输出保留，后续修订与底层技能变更分开记录。同一作者代理执行冻结版本可检验流程迁移，不是独立专家审美验收。


后续新论文迁移发现一项来源冲突：Nature Chemistry 2024 DOI10.1038/s41557-024-01553-6 的公开 Fig1d 工作簿表头与出版图的光/暗曲线对应不同。源值检查通过，但语义身份未通过。遇到类似冲突，应并列原图、表头、实际曲线，保留首次输出，把相关主张改为 contested 或 unknown，等待更正或独立原始元数据；不能为了重合而交换标签。该观察只针对指定公开版本，不能外推为其他数据有问题。冻结版本和后续指导修订分开保存。


## 实际刊载尺寸与源 PDF 排版（本轮三幅的实测经验）

先量源 PDF 中目标面板的裁切框，使用 pt / 72 × 25.4 得到毫米，并记录裁切范围；不要把面板和整页尺寸混用。重建要求同尺寸时，原图与成图都保持这一尺寸，文字用 PDF 基线而不是包围框中心定位。分子式的下标、斜体变量和加粗标签各自保留来源角色，不因为字体统一就改掉科学排版含义。字体相同但坐标或大小不同，仍会明显破坏版式。

当前 harness 的 `visual.layout_mode: exact_canvas` 可供已自行排好页内坐标的 schematic 使用：取消 constrained layout 的外围收缩，让场景填满指定物理画布。普通有坐标轴的数据图不要随意套用；必须留轴标签和刻度空间。场景 text 可用 `va: baseline` 与 `rotation_mode: anchor` 保留旋转文本的基线锚点，JSON 虚线格式为 `[offset, [dash, gap, ...]]`。

从 PDF 测量矢量几何时，零宽/零高路径仍可能是有效箭杆或坐标线；常规面积相交判断会漏掉它们。分组透明度也要与对象透明度一起处理，否则浅底色会变成实色块。这两项在本轮 the target method 中实际出现过；当前可移植测量脚本保存在案例中，不宣称是通用 PDF 重建器。遇到剪裁、混合模式、位图文字仍需回看真实导出。

定性 PES 的投影轮廓匹配，不等于得到可用的三维物理面。允许把明确说明的轮廓与材质控制点用于示意图重建；不得据此生成能垒、坐标刻度或能量数值。真实 PES 从真实坐标/能量和插值定义开始，另行验收。对照审阅应给物理尺寸和局部放大，并分别列剩余字形、几何、材质差异。原生文字与轮廓加栅格材料层，不能称为纯矢量图。


源 PDF 已包含目标标签的字形时，可在项目内用于对应原图驱动重建，配合角色字体文件与转曲导出稳定外观；保留文本规格和字体来源，不把它安装为全局默认。子集字符不全时不能用于新论文任意文字。转曲解决外观依赖，却降低 SVG 直接改字能力，应明确由场景 JSON 修改并重渲染。此法属于源图匹配，不能算从新材料独立设计成功。

物理画布、字体角色和定量/示意边界冻结后，新材料迁移允许编写项目专属数据转换与场景/recipe，不允许为了让新案例通过而暗改共享后端或冻结指引。先依据正文、源数据和读者问题提出不同故事，记录代理选择与用户选择的区别；保留首次图稿，再看原图比较。相同作者代理的迁移可验证来源和流程，不是独立专家视觉评审。
