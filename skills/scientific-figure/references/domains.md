# 领域规则和后端边界

## 配对与分布

保留样本 ID、独立性、n、缺失与不确定性定义。先按 ID 配对再画连接，不能按 CSV 行顺序配对。个体分布、测量误差、SD、SE、CI 与模型误差不能互换。没有区间数据时不要自动生成误差条或推断显著性。优先复用 Matplotlib/R 等可复现脚本。

## TableSpec

行实体、列指标、单位、分母、样本量、比较方向、精度、缺失/失败/零、突出规则和脚注需明确。单元格绑定源行与列。不同分母的性能不能直接排名；没有统计证据时不标唯一“最佳”。内置表格原样显示数值，空值显示 NA，不自动补零/加粗最优。

## 离散能量图与化学结构

输入状态 ID、物种身份、路径边、能量单位、共同参照态与条件。TS 的来源、连接的两端状态和反应步骤必须有依据。连接离散状态用有说明的线段，不画暗示连续计算势能面的平滑曲线。多路径的共同尺度与共同参照要先成立。

网络与能量图相邻时特别检查纵向位置的含义：若网络按拓扑排布，图面直接说明高度不编码能量，不能只靠图注纠正貌似能量曲线的布局。长档案 ID 可映射为本图局部别名和功能名，原 ID 留在图注映射；同一分支在结构、网络、能量图与 slide 保持身份编码。局部别名不能冒充原论文标签。此做法来自 C4 网络迁移中实际盲读的误解，适用于这类混合表示，不要求所有网络增加能量说明。

SMILES、SDF、XYZ/CIF 等结构资产保留实际身份和源文件。需要化学描绘时使用用户已有的 RDKit/化学编辑器等后端；价态合法并不验证机理。第一版 harness 不含化学身份/价态/TS 机理验证器，不能将通用方框当作原子结构交付。

## 三维 RenderSpec（真实 OVITO 后端）

使用独立 `$ovito-structure` 与 harness `structure3d`。保留分数占据率及显示周期像到源位点的映射；混合位点加权色不代表一个实际有序构型。当前是单帧原子结构/Tachyon 渲染，不覆盖电子密度等值面。

存坐标文件、晶胞、选择、周期复制、键判定、相机投影、裁剪、可见性、阈值/等值面、色标范围、标注和比例。可使用现有 ASE、OVITO、VMD、PyVista 等适合任务的后端，先查实际安装与官方文档，不自动安装整套工具。

相机/阈值改变属于影响解释的呈现。缓存若启用，按结构内容、选择和渲染参数判断复用。验证关键原子/区域未被遮蔽、跨周期键正确和共同色标成立；未实现的检查明确记录。

## 方法图

节点为真实步骤/对象，边区分数据流、时间顺序、物质转化、接触、包含和假设因果，并附来源与依据。并行分支、依赖、输入输出类型不能被版面改成串行。流程图的拓扑正确不等于科学因果成立。

## TOC/图形摘要（真实资产组版）

harness `toc` 提供 linear/evidence_hub/comparison 三种组织，绑定主张、已有结构图和原始序列；摘要 sparkline 不能代替有轴/单位的主数据图。它是可编辑组版，不是自动理解故事的模型。

从已支持的主张中选具体对象、干预/过程与结果。按内容选择线性、循环、并行或嵌套结构，保留小尺寸下辨认对象与条件所需的标签，不强制所有研究压成单线故事。用真实资产和可编辑矢量构图；若用户选择图像生成或图像编辑，应遵循可用图像工具的实际要求，并记录用途和工具作用，不能生成研究证据。

## 期刊与媒介

分开尺寸/格式/字体等制作规格、科研完整性和 AI 工具政策。记录期刊、用途（数据/解释图/研究图像/TOC/封面）、工具作用（规划/代码/组版/像素生成/局部修改）、官方 URL、核查日期、适用条件与披露。投稿前核对现行要求；本包没有通用许可结论，也不把某一期刊终稿字号用于所有媒介。

## 原始序列

`series` 按采集顺序连接行，不自动按 x 排序；压痕回线尤其不能排序。显式缺失策略只允许 x/y 同时为空的配对缺失，单侧缺值报错。`data-map.json` 保留实际行 ID 和顺序。XRD 特定 `xrd_uniform_grid` 适配器核验起点/步长/终点和每个强度；它不执行 Rietveld 精修。其他转换若未实现仍报告未实现。

## 火山曲线与条件地图（ACS Catalysis 存档案例）

适用于从微观动力学数值存档重绘浓度火山图、选择性地图：先区分作者处理后的描述符曲线、逐催化剂计算点和原始求解输出，不能把点数组当作曲线的独立验证。核对网格轴顺序与条件变换；log10秒改为小时刻度时保留对数坐标与原格点。显示域与源域分别记录，避免把域外插值伪影误报为图内问题，也不能悄悄截值修饰结果。

比值地图必须区分零、缺值与中性：两产物均零是未定义，不能填成1:1；单零的无穷比值与色阶饱和分别说明。中性颜色和等值线只表达中心预测相等，不是置信边界；图面给线与特殊缺值色一个小图例，模型限制与可用区间留在图注，不能凭平滑色面宣称可靠。浓度、选择性和活性不能互相代称。此规则来自 ACS Catal. 2024, DOI:10.1021/acscatal.4c01175 的 Fig.4d–g、SI S1 与实际存档检查；不是所有热图都需要选择性解释。
