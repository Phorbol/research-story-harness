# 有条件的设计原则：从教材到具体改图

以下是设计依据与本 harness 的应用推断，不是期刊统一模板或已证明的审美定律。源教材支持原则；具体配色、几何、字号和材料表示仍需在目标图上验证。先定位失败层，再选择改法。

| 适用情境 | 决策与可观察信号 | 边界/依据 |
|---|---|---|
| 图漂亮但读者不知在比较什么 | 先写清读者需要完成的判断，再决定对象、关系和编码。若一句话说不出图与主张的关系，暂停增加细节 | Munzner 区分领域问题、数据/任务抽象、编码/交互、算法；下层实现正确不能补救上层错误。[课程讲义](https://www.cs.ubc.ca/~tmm/talks/vad/VAD-nested-4x4.pdf) |
| 机制图退化为普通流程图 | 材料相互作用围绕材料对象组织；循环反应保留循环和分支；真正的数据处理才使用阶段流程。检查箭头到底表示反应、数据流还是因果 | 这是结合领域原图的应用判断，不是“禁止方框”。几何应帮助辨认对象和关系，不能增加未支持的活性位 |
| 多面板难比较 | 配对面板采用一致的颜色语义、可比尺度和明确阅读顺序；用物理尺寸安排间距。先看读者能否跨面板定位同一对象，再追求对称 | Wilke 第21章讨论共同尺度、面板顺序与一致性；非可比量不能强行共享轴。[教材](https://clauswilke.com/dataviz/multi-panel-figures.html) |
| 所有内容同样抢眼或配色混乱 | 区分分类色、连续量色、强调色。将主要路线/发现做视觉重心，次要路线仍须可读；元素色不兼作速率或能量标度 | Wilke 课程强调颜色的不同功能及上下文/数据平衡。具体色板是设计选择，需检查灰阶和缩小后的辨认。[课程](https://wilkelab.org/dataviz_shortcourse/slides/figure-design.html) |
| 大屏好看但论文尺寸拥挤 | 先确定媒介与图的任务，在最终物理尺寸检查标签、线宽、空白和阅读顺序；标题、变量、单位和图例使用角色化文字规范 | Rougier 等强调读者、信息与媒介，以及默认设置的局限；不由此推导统一期刊字号。[Ten Simple Rules for Better Figures](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1003833) |
| 能量差需要读者自行心算 | 从同一参照下的源状态生成局部差值、括号和端点引导线；激活差需要已报告 TS 与相邻关系，脱附态差不自动成为动力学势垒 | 本案例的可复用组件规则；不是上述通用教材的化学结论。单位、参照态与状态身份先核实 |
| 渲染更逼真，反而容易误读 | 原子图同时声明模型来源；构造模型只承担概念语境。比较图固定尺度和视角，说明哪些几何是有意构造 | 本案例来源边界；不把渲染器成功或原子数量正确作为结构真实性证据 |

## 用论文图检验原则，而不是收集期刊皮肤

记录实际看过的图及图注，拆为：读者任务 → 科学对象/证据 → 拓扑与视线顺序 → 编码/文字层级 → 可迁移策略 → 失效条件。保留作者明确表达与自己的解释。只读题目或元数据不算图件学习；完整查看也不算完成复现。

例如，催化循环的关键是连通与分支，而 E(3) 模型架构可通过重复的原子邻域与逐层数学表示来解释计算。两者都含箭头，但不该套同一种布局。定性 PES 总览可以作概念示意；它的漂亮曲面不能直接移作计算结果。

在当前甲醇重整案例中，已经实际测试了：材料对象取代装饰性半圆、同尺度双面板、源状态绑定的局部差值、最终尺寸文字检查。其证据是同一案例的前后图与源值核对；没有独立读者验收，尚不支持“各种论文均可自动出版”的结论。

修订后保留此前失败图和具体原因。新论文迁移若不能改善读者判断，应调整或撤回这条局部策略，不能用参考数量或运行成功来提升其可信度。
