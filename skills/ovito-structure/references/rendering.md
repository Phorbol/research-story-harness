# 从可辨认到美观的结构渲染

## 相机与版面

先问要看吸附位点、配位、层状结构、孔隙、缺陷还是两种结构差异。正交投影利于尺度/角度比较；透视更有空间感，但近大远小可能改变比较。俯视加斜视常有互补性；不是所有结构都必须两视图。

用 `zoom_all(size=...)` 先拟合，再调整 fov 留白；保存实际 camera_pos/dir/up/fov。两种结构共用方向并校准显示晶胞尺度。本案例将短 c 的混合占据模型沿 c 复制三次，与长 c 的有序模型比较；复制不是增加独立样本。

不要只因“坐标没变”就判定呈现没变：相机、裁剪、透明度和半径可能遮住关键位点。保存 must_show_sites/elements 检查选区，再查看每个实际视图。当前没有自动遮挡充分性证明。

## 原子、混合位点和邻接

显示半径与真实原子尺寸是不同对象。半径过大可能遮住小元素，过小会破坏连接辨识；调整时保持同类图一致。元素使用固定的语义颜色；连续属性才使用有单位、共同范围的连续色标。

混合位点有多个合法表示：扇区、明确注明的混色、概率/占据率表，或具体有序近似。当前 CLI 支持加权混色并保留每个元素比例；任何原子级有序近似应另建科学对象，不能无声替换。空位占据率也要保留。

距离邻接需写 cutoff、单位、边界/PBC 规则与含义。跨周期的向量应包含晶格位移，不能直接将盒子两端的原始坐标连接为长键。需要真实化学键或配位多面体时用领域依据定义；本版未实现自动配位多面体或电子密度等值面。

## 渲染器和质量预算

先用 draft（本脚本 AO 12、抗锯齿 4）确定科学可见性与构图，再用 final（AO 40、抗锯齿 12）输出。它们是本包起始预算，不是普遍最佳参数。AO 增强深度，但过暗会隐藏内部位点；强阴影和景深模糊可能使科学对象难以比较，因此本脚本不默认启用。

Tachyon 提供 CPU ray tracing，输出 PNG；不能因此承诺宿主完全不需要图形初始化。OSPRay 或其他后端应在实际版本中检查可用性后显式切换，保留变更理由，不静默回退。

导出先确定最终物理尺寸与所需像素密度，再渲染；不要靠把小位图嵌入 SVG 声称无限缩放。图中文字放在 Matplotlib/SVG/PDF 组版层，保留文本可编辑性；结构位图由源文件、场景和脚本重新生成。

## 定向修改例子

“增大 O 原子使其更清楚”：影响解释的呈现，检查 Ta/Cr 是否被遮；“改相机”：重查关键位点；“只提高抗锯齿”：质量参数，保留相机与源结构；“换一个 CIF”：科学输入变化，核对元素/占据率/晶胞/图注和正文；“调标签字体”：使用共享文字角色，不重新渲染科学结构。

## 坐标重渲染与参考示意重建

先区分真实坐标、理想结构和手工解释几何。若参考原图本身是金属块、放大镜和投影球体的说明图，可以用独立场景重建，但不能标成恢复作者 DFT 坐标。真实坐标渲染需要保存实际结构；视觉学习可比较原图的比例、视角、光照与标注，不能借换示意坐标获得“更像”的结果。

当前 CLI 支持 spec.transparent_background、background 与 cell_line_width，利于无白框地嵌入多面板。输出时仍检查位图像素尺寸与真实可见性。

## 半径过小的实际修正（2026-11-05）

旧示例统一使用约 `0.42 × ASE covalent_radius`，对致密晶体和金属表面会显得细碎、间隙过大。已用有序 Cr–Ta 氧化物坐标、理想 Cu 表面模型和真实 Rh 配合物坐标，固定每组相机分别比较旧表示、只增半径、半径加光照三列；原子、占据率和邻接保持不变。以下是这些案例的起点，不是所有材料的最佳值：

| style_preset | 半径起点 | 邻接宽度 | 光照起点 |
|---|---|---|---|
| solid | 0.90 × 共价半径 | 无邻接时不补键 | AO brightness .78，direct light .72，投射阴影关闭，保留 AO 接触阴影 |
| surface | 0.94 × 共价半径；C .66 Å、O .60 Å、H .32 Å | 金属球体接近填满表面，不自动画所有近邻键 | 同 solid |
| molecule | 0.72 × 共价半径；H .32 Å | 有来源的邻接以 .18 Å 柱体起步 | AO brightness .82，direct light .72，投射阴影关闭，保留 AO 接触阴影 |

半径增加后检查吸附物、小元素和中心配位。需要看到内部位点时可减小遮挡元素的半径或提供互补视图；不要让“更紧凑”变成所有结构都用最大球。保留结构本身的真实孔隙。

### 可编辑参数与优先级

`style_preset` 提供起点；显式 `radius_scale`、`element_radii_angstrom`、`bonds`、`render_settings` 优先。绝对元素半径覆盖该元素的共价半径比例，单位 Å；混合位点按原有占据率加权，未改成主元素替换。无预设的旧规格仍使用旧默认，保证既有图稿不被无声重绘。

```json
{
  "style_preset": "molecule",
  "radius_scale": 0.72,
  "element_radii_angstrom": {"H": 0.32},
  "bonds": {"mode": "none", "width_angstrom": 0.18},
  "render_settings": {
    "ambient_occlusion": true,
    "ambient_occlusion_brightness": 0.82,
    "direct_light": true,
    "direct_light_intensity": 0.72,
    "shadows": false,
    "ambient_occlusion_samples": 40,
    "antialiasing_samples": 12
  },
  "transparent_background": true,
  "crop": true
}
```

此例没有生成键；来源拓扑或显式距离邻接需另行提供。返回的 `display_radii_angstrom` 和 `render_settings` 记录实际效果所用值。

### 构图与公平对照

`zoom_all` 后的 framing 随半径变化，不能把变焦和球体增加混为一谈。正交视图可用 `fov_angstrom` 与 `camera_pos_angstrom` 固定每组对照的世界坐标相机，并设 `crop:false` 保留相同画布。展示时可对整组使用同一个透明边距裁切框；不单独放大某一列。

论文组版的单图可以设 `crop:true` 收紧透明边距；原视口 size 和 fov 仍记录在场景中，实际 PNG 尺寸以图像文件为准。此类裁边只解决外部留白，不能解决原子间的视觉空隙。

光照字段已在本机 OVITO 3.16.0 运行；[官方 Tachyon 参数说明](https://www.ovito.org/manual/python/modules/ovito_vis.html#ovito.vis.TachyonRenderer)支持 AO brightness、direct light intensity 和 shadows。当前在线文档还含后续版本字段，不能直接假设本机有新增的 Material/PBR 接口。本次改变的是球体、柱体和光照观感，没有声称校准材料的真实光学属性。

高清检查又发现致密 Cu 球体接近相交时出现硬接缝；表面起点由 .98 调至 .94，并关闭方向光投射阴影、保留 AO 深度。它仍显著大于旧 .42 表示，留出很小的原子间隙。半径/视角不同的体系应重新检查接缝与遮挡。
# 指定距离的可见归属（Co催化剂/有机载体案例）

2026-11-09真实坐标对照中，数值正确但Co遮挡、多个N不能区分，距离线曾从空白处起始。有效修正是先换相机暴露Co，再用最终相机和裁切后的原子中心投影放置测量线；圈标和源原子编号引线指定被测N。不能手调端点到“看着像”的球上。若N仍部分遮挡，明确记录，不声称所有原子完全暴露。

局部裁切保留全部69个催化剂原子及所需支持片段；清除与目标无关的孤立裁切碎片，未显示的连接以截断延续符说明。保留源原子映射和未变坐标，对照图共用尺度。该办法适于有限模型的指定接触比较；6.51 Å分离线是测量引导，不是化学键，也不用于推断成键或反应机理。
