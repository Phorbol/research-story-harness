# 负载颗粒：实测/计算坐标与理想示意模型

用户提供的照片或示意图可以指导构图、材质与视角，不能单凭图像恢复原子坐标、晶相、合金排布或接触角。先决定图的任务：研究实际结构时索取 CIF/POSCAR/XYZ/轨迹；解释材料概念、且用户接受理想模型时，可用 ASE 构造，并在图或紧邻图注标明 **idealized model / not source coordinates**。不要把两种来源混写。

## 构造与保留

- ASE `build.bulk` / `build.surface` 生成指定晶相和晶面的载体；有限颗粒可从明确晶格裁切或用 `ase.cluster` 构造。晶格常数、截断方式、表面终止、原子数、组分替换、随机种子、界面间距、周期边界与是否弛豫都属于模型假设，存入来源记录。
- 以 tags 或明确原子索引区分载体和颗粒；写出 extxyz 并保留 `atoms.info.model_origin='constructed_illustration'`、`not_paper_coordinates=True`、`not_relaxed=True`（仅在确实未弛豫时）。`structure_render.py` 会将这些字段带到 scene.json。
- 构造参数是示意选择时，不能用其精细外观证明真实组成、外延关系、界面结合、接触角、活性位或机理。没有来源，不添加“测得”的角度、吸附构型或比例尺所暗示的实测粒径。确有尺度时，区分模型尺度与样品测量。
- 比较元素或表示效果时固定几何、替换位点、相机与比例。只有科学问题确实比较粒形且有来源时才改变粒形；不要为视觉差异擅自增加物理差异。

## 密实感与材质

先检查主视角的接触界面与轮廓，再调球半径。用半径接近近邻距离一半作为密排显示的试探起点，不能覆盖多孔结构或分子空腔。半径是显示参数，不是新测量的原子半径；保留实际坐标。

固定 `camera_pos_angstrom`、`fov_angstrom`、`crop:false` 比较半径版本，避免放大视图掩盖问题。载体与颗粒必须有可辨的形体层级，但不能通过截掉关键位点实现。偏斜正交视图通常有利于同时看表面和界面；按对象决定，不强制固定角度。

柔和 AO 可表现球间接触，过强 AO 会把孔隙和界面压黑；直射光和投影阴影分别调整。最终从论文尺寸判断表面是否像“密实材料”，不是只看放大截图的高光。增加采样只解决噪点，不解决空洞、遮挡或配色。

元素色和反应路线色各自保持一致；元素图例放在矢量组版层。对照结构用同样透明画布嵌入，化学式、箭头与数值保留可编辑文本。构造模型是材料语境，反应路线及定量结论仍绑定论文/数据来源。

小分子可以用真实分子坐标，或按已知连接关系构造明确标注的理想分子，作为机制节点的补充；用球棍表示比密排大球更易读。分子自身几何、气相示意摆放和表面吸附构型是三件不同的事，不能从前者推出后两者。只有在目标尺寸下构型辨认确有帮助时才加入；若球棍缩小后只成一团，保留化学式或使用局部放大。未知吸附坐标不通过“把分子放在表面上”补齐。

连接到分子/公式的箭头应绑定对象边界端口，检查箭头末段是否朝向实际节点，而不只是落在其附近。短的释放箭头优先直连；绕行曲线的曲率、端口及留白一起调整。曲线不是越多越有机制感，箭头的语义和归属才是验收点。

此流程已用于同形 Pd–Zn/Pd–Cu 颗粒与 ZnO 载体示意。该例的 35% 替换比例、球冠裁切和界面间距是局部示意选择，**不是可推广的科学默认值**。更换论文要重新确认晶相、模型职责与来源，不继承这些参数。
