# OVITO 结构渲染

先确认坐标来源、希望辨认的科学对象，以及图要帮助读者做的判断。真实坐标与构造示意模型分开记录。美观优化应保持结构身份、占据率和必要可见性；不要把删掉关键原子当作简化。

负载纳米颗粒、团簇/载体示意或用户允许 ASE 构造时，读 [理想模型与负载颗粒](references/illustrative-models.md)。允许构造不等于可以把理想模型宣称为论文结构；缺少真实坐标时说明缺口与模型职责。

## 先检查输入与环境

读取项目指令、文件格式、坐标单位、晶胞/PBC、帧和结构身份。CIF 可能有分数占据率：ASE 的主元素数组/化学式可能省掉少量元素，必须结合 `info.occupancy` 与 `spacegroup_kinds` 恢复位点组成。区分有序近似、混合占据模型和真实实验结论。

本包在 Python 3.12、OVITO 3.16.0、ASE 3.26.0 上验证。使用项目隔离环境或已有 `ovitos`；依赖见 `assets/requirements.txt`。不因文档示例声称支持某格式而跳过实际导入检查。

## 使用附带脚本

```bash
python3 <skill>/scripts/structure_render.py actual.cif render-spec.json --out renders --quality draft
python3 <skill>/scripts/structure_render.py actual.cif render-spec.json --out final-renders --quality final
```

渲染规格样例在 `assets/render-spec.json`。输出是真实 OVITO Tachyon 图像与 `scene.json`，保留源摘要、原始位点、完整占据率、显示周期像、距离邻接、相机和软件版本。三维图本身是位图；文字、图例及版式在论文绘图后端中以矢量叠加，不能把整份 SVG 宣称为原子级矢量。

新图按对象选择 `style_preset: solid | surface | molecule`；样例另有 `assets/render-spec-surface.json` 与 `assets/render-spec-molecule.json`。它们是三类坐标模型目视调图得到的起点，仍需检查关键位点遮挡。旧的无预设规格保留原行为；不要把旧 `.42` 半径比例直接当作所有论文结构图的默认值。分子预设不自动生成键，需来源拓扑或明确声明的距离邻接。

通用 OVITO 流程是导入/构造 `DataCollection` → `Pipeline` → 加入 scene → 配置 `Viewport` → 指定渲染器。需要从 LAMMPS、轨迹或已有 OVITO pipeline 开始时读 [Python 工作方式](references/python.md)；需要调图时读 [渲染与优化](references/rendering.md)。当前 CLI 用 ASE 读取其支持的单帧格式，未覆盖的格式使用官方 import_file 工作流并验证字段。

## 催化表面与反应状态

扩展金属表面、吸附物和多状态近景可用 `scripts/surface_render.py`。先读 [催化表面渲染](references/catalyst-surfaces.md)，再从 `assets/synthetic-catalyst-example/job.json` 启动明确标注的合成测试示例；用于研究时替换为有来源的真实坐标。它以显式来源标签/编号区分基底与吸附物，仅铺展基底、保持吸附物单份、共用相机，并输出源原子与显示像的对应。它与通用结构入口互补；混合占据、有限团簇和多孔骨架不能直接套密排表面样式。harness 的 `catalyst_surface` 后端可把图像、原子标签与局部距离一起组版。

## 优化顺序

1. 先选视角和上下文：特征是否可见、投影是否适合比较、需要一个还是两个互补视图。
2. 再调整表示：周期像范围、显示半径、距离邻接/真实拓扑、元素或属性色。距离阈值不是化学键证明；不同结构比较时共用相机、比例与颜色。
3. 再调整光照和质量：先低成本预览，再提高抗锯齿与 AO 采样。阴影、透明度、深度模糊不得掩盖科学内容。
4. 最后与正文、图例和排版配置对齐：统一字体及字重/斜体，化学元素与单位正体，变量按语义用斜体。

每次明确哪些是科学对象变更、影响解释的呈现、纯质量参数。保留已接受的标签、选区与颜色。相机变化后重新目视核对遮挡；自动“有原子”检查不等于关键位点可见。

“球太小、很空”先区分球间空隙与画面边距：前者调显示半径和键宽，后者调相机及透明边距。比较半径时固定 `fov_angstrom`、`camera_pos_angstrom` 并设 `crop:false`；正式组版可设 `crop:true` 收紧透明边距。返回记录含实际显示半径和光照参数，避免靠不同放大倍率声称表示改善。具体字段见渲染参考。

机制/能量图中的结构近景须解释指定状态或事件。先确认目标键、吸附位点及必要共吸附物在最终嵌入尺寸可辨，再决定金属底板的范围；不要让大铜球遮住反应中心，或以占据大面积的漂亮底板替代化学变化。俯视遮挡接触区时试近侧斜视，裁剪不可切掉关键物种；比较图保持可比尺度。距离标注连接真实投影端点，并通过状态/TS编号关联网络或能量事件。二维网络通常优先RDKit等规范结构表示，三维用于空间/配位关系；两者不能将吸附态悄悄替换成中性分子。

## 运行边界

默认脚本保持分数占据率，以明确注明的占据率加权颜色表示混合位点，并保留各元素比例；它不生成一个虚构的原子级排布。周期键仅在两端显示周期像都存在时绘制，相关边界规则写入场景。

在本机，沙盒内即使选 Tachyon 仍遇到 Metal 初始化失败；宿主授权执行相同命令后成功。出现 `No MTLDevice` 时先定位实际图形访问/驱动限制，遵循宿主权限流程，不将空图或自动更换数据当作成功。独立脚本不修改权限。

与 `$scientific-figure` 配合决定图的论证职责；与 `$research-harness` 配合执行源绑定、TOC 组版、文字审计与连续修改。本 skill 自身可单独使用，不要求新建整篇论文。

反应小分子被大球/高光或基底遮住时，可从[催化表面渲染](references/catalyst-surfaces.md)的低高光可选片段起步；它只在Cu上的C/H/O近景有案例证据，不是所有材料的默认风格。
