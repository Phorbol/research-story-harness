# 分用途检索

## 科学证据

以当前命题、最近工作、竞争解释和已知限制构造查询，记录实际平台和日期。优先可检查的原始研究与官方数据。需要最新信息、具体页面、论文或精确引用时实际检索/读取；工具不可用则说明范围，不凭记忆生成 DOI 或作者。

检索记录可采用：

```json
{
  "purpose": "scientific_evidence",
  "question": "当前结果是否足以区分机制 M 与 N？",
  "queries": [],
  "platforms": [],
  "searched_at": "实际日期",
  "included_source_ids": [],
  "excluded": [],
  "coverage": "实际检索范围",
  "gaps": ["尚未取得全文的来源"]
}
```

空数组是未执行状态，不能报告为已完成检索。文献身份核查可比较出版页/DOI 元数据与正文；预印本、接收稿和期刊版保留对应关系。引用的版本与实际阅读版本一致。

## 表达范例

优先匹配当前论证处境：负结果、有限机制证据、不公平基线需要说明、观察性数据的克制讨论、贡献收束等。再考虑研究设计、读者、文章类型和期刊。没有足量全文也能产出暂定范例画像，保留样本数和选择偏差。

对冻结库检索，保留候选、匹配理由、同分情况和最终选择。标签同分后的固定排序只保证可复算，不代表相关性优胜；若只是低分泛标签匹配，检查论证功能是否适用，必要时不用该范例。区分原文段落范例、分析者的修辞释义和一般编辑原则；只测试了释义库时，不声称验证了原文范例检索或联网检索。

## 政策、教材与作者偏好

期刊政策查当期官方作者指南，记录必须/建议/常见的强度、文章类型与触发条件。教材提取原则的目的和例外。作者偏好需要作者表达或明确接受记录，不从一次编辑默推永久偏好。

## 取材与存储

source.artifact 存项目内可检查文本快照路径；source.locator 记录原始 URL/DOI/本地文件与原位置。bibliography 可存 doi、preprint_id、published_version、authors、year 等字符串；原文抓取日期写 retrieved_at，覆盖限制写 coverage。

关键数字、公式、表格、图注回到页面或原数据。记录解析失败，不把扫描缺字和缺表当成文章没有该内容。获取与页面检查使用当前可用、已授权的连接工具或文档工具；不声称 harness 内置浏览器、OCR 或付费全文获取能力。
