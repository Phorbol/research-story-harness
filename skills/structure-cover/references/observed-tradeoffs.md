# 2026-11-19 实际制作结果与适用边界

验证对象：既有1413原子Pd–Cu/ZnO理想未优化模型；RDKit ETKDGv3(seed17)+MMFF生成的咖啡因与阿司匹林示意构象。两后端使用同一坐标、显示半径和正交相机；分子连接取RDKit拓扑，显示杆不编码键级。未尝试复杂蛋白、电子密度或透明溶剂。

实际失败：首稿Blender三个强面光源把材料变成高光密集的亮珠，氧/氮颜色冲淡，320px缩略图比哑光OVITO更乱。提高金属粗糙度0.26→0.40、非金属0.36→0.48；降低主光85000→35000、边光100000→25000、补光30000→6000（本场景单位和距离下）后，色彩恢复，颗粒/载体层次改善。这些功率不是物理材料参数或通用灯光预设；脚本随视口尺度平方缩放光功率，仅作为此类有限对象的起点。

有效之处：主体完整渲染为透明图，然后与标题/背景分开；同构图对照避免把放大倍率当材质改进。大块暗背景提高轮廓对比，但碳原子过暗时仍要补柔光，不应改掉碳的科学身份。标题与主体分区后，320px下仍能辨认材料颗粒与小分子；小字来源信息需要原尺寸阅读，不能依赖缩略图承担科学限定。

取舍：OVITO更干净，元素色更容易区分；Blender修订版更有立体材质，但仍有更多高光噪声。没有单一赢家。方形封面是完整主体重新排布，不是横图中间截取。比较未进行用户点击率实验，也不是独立盲评或发表级认证。

可复用的是固定科学对象、先比较再修光、将渲染与封面组版分离的实际脚本；不是“所有封面都要深蓝背景/金色颗粒/左文右图”。实验产物保留在 structure-cover-20261119 案例目录；本 skill 附有可运行小分子scene及两类配置，不依赖该绝对路径运行。

## 第二轮：塑料珠子感与版式单一

把Pd/Cu的Metallic设为1、载体设为高粗糙度非金属，且将三个圆形面光源换为两盏矩形灯，材料间的响应更容易区分。低粗糙度0.28/0.30的纯金属版本产生更碎的互反射；提高至0.48/0.46的缎面版本更适合当前颗粒缩略图。这是艺术化原子球体表示，不能理解成真实材料表面或光学参数。三版同相机、同半径、同坐标的实际渲染均保留，未只凭参数推断效果。

小分子的居中特写、双对象并置、方形上图下标题均已运行并看320px图。方形让单对象占据更大面积；并置适合比较但单个对象相对变小；横向居中需要精简标题并提高字号，不能直接继承大图里的小标题。这些是有条件的构图选择，不能宣称全都比左文右图更好。并置对象没有箭头，不应暗示反应或相互作用。

实际字体失败：Hiragino Sans GB可显示中文却缺少所用Unicode下标，化学式出现方框；逐段使用已验证涵盖下标的DejaVu Sans后恢复。组版器增加真实可执行的逐段字体与锚点支持；示例配置中的字体仍须在目标机器核对。
