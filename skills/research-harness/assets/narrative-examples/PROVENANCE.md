# Public narrative templates

The JSON files are editable explanatory templates; any generalization from their geometry requires task-specific judgment. `parallel-training.json` uses generic method identifiers for a parallel-training diagram.

`qualitative-landscape.png` is freshly generated by `generate_landscape.py` from arbitrary Gaussian functions and a quadratic background. It is explicitly labeled synthetic, has no physical units, and is not a learned potential, measured energy surface, or reconstruction of an observed surface. Run the script in the root plotting environment to regenerate it.

`surface-cycle.json` and `structural-zoom.json` retain their public reference locators and conceptual/illustrative scope. No original publisher page, extracted font, or original paper image is included here. The templates are local diagram constructions, not a claim of reproduced scientific evidence.
