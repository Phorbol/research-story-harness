# 条件地图的文字与版式配置

画布为 148.16 × 126 mm。`config.json` 集中保存字体、文字角色、字重、颜色与分面配置；`figure.py` 定义数据与几何的关系。使用自己的数据时先核对坐标、单位和条件，再调整样式。

| 文字角色 | 基础字号 |
|---|---|
| 坐标标题 | 7.8 pt |
| 刻度 | 7.3 pt |
| 参考标签 | 7.4 pt |
| 比值与科学说明 | 7.5 pt |
| 图例与标题 | 8 pt |
| 面板字母 | 9 pt，加粗 |

数学上下标遵循数学排版比例。面板字母承担粗体层级，L1/L2/L3 不另外通过字重编码科学意义。温度地图中的 panel a / panel b 是跨面板索引；精确温度位于上排标题中。

## 修改与查看

在本例目录运行：

```sh
python run.py --out build
```

打开 `build/condition-map.pdf` 检查实际画布尺寸下的刻度、参考线、图例和状态标签。调整字号时同步为标签留出空间；避免直接缩放整张图。保持颜色语义、等选择性轮廓、灰色 0/0 区与源网格不变，除非明确修改了数据表示。

科学定义与来源见 [SOURCES.md](SOURCES.md)；现有验证范围见 [VERIFICATION.md](VERIFICATION.md)。样式修改不等于重新求解动力学或验证模型。
