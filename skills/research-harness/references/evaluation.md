# 验收与覆盖范围

## 分层判断

首先记录正在验收的用途、物理尺寸／演示画布与依据。来源不明的工作画幅只能按工作稿评，不将其结果改称期刊尺度通过。单独记录“源文件尺寸正确”“放入目标框后可读”“叙事与审美满足任务”；其中任何一项都不能替代另外两项。已有PDF可用 publication_components.audit_publication_size 作第一项的只读检查。

1. 来源与科学约束：真实输入、对象身份、单位/参照、关系、样本与主张边界。
2. 读者任务：只看图和实际目标上下文，能否辨认比较对象、条件、差异、误差和关系；是否产生过度推断。
3. 布局：实际物理尺寸下字体、标签、图例、裁剪、色彩与可见性。
4. 风格：满足媒介要求与用户偏好。

不能将它们平均成单一分数，也不能用来源相同的多次自评冒充独立验证。自动检查定位已实现的错误，人工评估回答工具无法判定的问题。记录 unknown/not_implemented 是完成覆盖报告，不是完成科学验收。

## 包内回归与真实任务的区别

基础 tests 使用明确标注的合成输入，验证四类图的导出、对象映射、缺失/零差异、参照/边对应和五次连续修改；通过只说明这些受控软件行为有效。

扩展 tests 使用受控占据率/周期邻接案例，并检查真实 MatterGen 规格的绑定、原始轨迹缺失规则和 XRD 转换。软件通过不代表科学结论成立。

项目的真实验收仍需相应数据与专业判断。按调研建议选择三至五类日常任务，每类完成初稿、两次典型修改，再做连续五次修改；次数是开发预算，不是统计规律。至少包含：参考逻辑迁移、增删对照、换单位/参照、调换面板/布局、更换期刊尺寸中的相关情景。连续修改试验应保存初稿、每次规格与实际导出，并分别记录重新计算、重新绘制及只改变呈现的范围。

故障注入需能定位而不只是报低分：重复/错配样本、缺失被补零、TS 接错状态、并行分支变串行、相机遮蔽关键原子、图注将支持写成证明。区分软件可定位的问题与必须用独立来源/专家判断的问题；例如宽表中已写错的样本值无法凭同一表自动证明错配，已保存的保护项和原始实验记录才提供比较依据。

## 结果记录

逐图记录输入版本、操作、必须保持、导出和验证记录；另记录耗时、人工修订次数与计算成本（若实际可得）。不要凭合成样例给出生产力提升百分比。改进规则需基于真实失败与留出案例，不把单次补丁提升为通用规律。

当前报告的自动通过不覆盖：统计假设/显著性、文献结论真伪、化学身份/价态、TS 机理、因果、三维可见性、盲读理解或出版许可。像素/版面目视检查也不能验证上述科学事实。

## 论文成图的实际验收（v5新增，针对已观察到的排版/类型混淆）

用户要求的默认交付是可用于论文的正式图件；不要把可运行demo、数据匹配或技能包存在当作成图完成。先确认图件任务与目标刊载尺寸，再在该尺寸打开真实PDF/PNG检查文字和局部几何。导出可用PDF/SVG与按目标媒介明确配置的PNG分辨率；600dpi可用于需要高分辨率位图的任务，并非所有期刊的统一规定。`visual.export_dpi`只改变导出采样，不能修复构图或模糊源素材。字体审计检查实际属性，不认证好看。

分开判断：科学主张与来源支持；图/表类型是否适合读者动作；字体/颜色/粗细/斜体与空间层级是否一致；最终页面尺寸下是否清晰、平衡、无碰撞裁切。示意和定量分别核对，不能用其中一条通过替代另一条。检查结果记录具体图号、范围、实际观察和仍有差距的位置；失败保持失败，不修改标准来凑通过。

**原图复现与重新设计是不同验收。** 忠实复现先比较相同对象、关系、信息层级、构图和视觉编码。改变图型、统计汇总、版式或读者任务时，应另列为重新设计，解释它强调/隐藏什么；不能把它放在“原图已复现”一栏。数值表承担精确查值，热图承担颜色编码的模式比较；格内有数字不会把颜色矩阵变成原表复现。表格采用一致的小数、对齐和表头/单位/注释；不存在支持的显著性或最优判断，不自动加粗。

按角色明确字体规则后逐一核对真实导出：同类标签字号/字重一致，变量和单位按语义处理，跨面板基线、中心线、重复对象尺寸和箭头起止点有意对齐。若模仿源图，逐对象核对节点数量与位置，不能用“一个差不多的网络图标”冒充原图。参考图局部字体不可取得时说明替代，不因此强称精确复刻。

人工记录继续使用现有 scientific/reader/layout/publication 类别。代理自己看图可以记录实际修正和剩余问题，但不能冒充独立读者或作者的审美认可。没有实际作者选择或刊载尺寸验收时，保留为待审阅成图，不宣称已获投稿验收。与用户协作时直接呈现具体成图和针对性差距，不要求用户先写完整故事或图型清单。


## 用户质量反馈的优先级

读者能复述故事、没有撞字、代理表示喜欢，都不足以判正式论文/汇报质量通过。并排审查还需说明：必要信息是否流失、视觉重心是否对应贡献、结构/文字/数据的面积比例是否失衡、分子细节与箭头是否在真实尺寸可辨；审阅记录具体对象和差距。用户明确指出远不如原版时，当前稿保留未通过，先修关键完整构图单元，再扩同批页面；见[反馈到制作动作](feedback-to-practice.md)。已有用户反馈不能被同模型的多次肯定覆盖。

独立迁移须分开自主首交、独立反馈后自修和主代理救场，执行边界与盲读顺序见[independent-transfer.md](independent-transfer.md)。正式图与完整汇报均应实际打开；制作端自修次数可记录，但不是质量分数。

Al卟啉v10案例中，自查承认结构深度重叠、能量面板稠密仍判可读；盲读者却无法直接看清配位端点。审阅时记录具体读者动作及图面证据：看到哪些对象、哪条关系连接了它们、哪些身份／数值／限定能在目标框读出。不要用“已打开”“无碰撞”“图注解释了”替代该证据。评审新增前提要单独记录，不能回写旧报告使一次有辅助、改过条件的实验看似无辅助成功。
