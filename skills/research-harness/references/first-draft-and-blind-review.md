# 首稿视觉决策与严格盲评

适用于复杂论文转TOC、概览图和完整汇报，以及用户明确要求的独立迁移试验。它针对已观察到的两种失败：所有内容等重的首稿，以及“可读但仍有实质缺陷”被自评放行。下面是待前向验证的工作方法，不是已证明普适的设计定律。

## 用实际对象试构图，而非先承诺版式

适用于复杂概览、方法关系或跨面板论证存在实质构图不确定性时；简单局部修改不需要此环节。上一次电化学试验已经写出合理故事，并生成两张候选，但候选只是写着科学主题的空框。它们没有检验对象尺度、主次或读者能否走到研究结论。后来添加真实数据面板，也没有自动恢复跨面板关系。因此这里替换“先写候选再填版式”为下面的实际制作动作，效果仍需前向检验。

**先找不可断开的阅读单元。** 从读者最终能作出的判断倒推必要对象和证据，沿用 story/claim ID；区分“材料含有哪些主题”与“读者如何从一个观察走到下一个判断”。比较图可能依赖共享尺度和对照，方法图可能依赖反馈与停止条件，空间图可能依赖邻域和尺度；不把闭环规定为所有科学图的拓扑。把图内必须看到的起点、判别依据和结果作为同一个表达单元。决定移去图注的是条件细节还是主关系，不能事后用图注补回主关系。

**用真实对象做有竞争力的试片。** 对仍不确定的空间组织，实际摆入关键结构、源数据形态、操作对象及其连接，以最终毫米框渲染。初期允许粗画、未精修材质，不能用“这里放方法/结果”的文字框冒充可比较候选。候选需要改变读者的比较方式或空间关系，不是仅改变分栏。先保护决定判断的单元与必要文字，再分配辅助对象；不先平均分栏，也不先给引言式反应/标题固定一整行。若一个候选因核心端点挤不下而失败，应淘汰或重构它，而不是删终点、缩小核心字或扩大图框。

**看图选择，而不是按文字理由选择。** 用 `scripts/composition_probe.py` 将候选 PDF 在同一原生尺寸并排。先不用设计说明，记录实际先看到什么、能追到什么判断、在哪里断开，以及相对参考的对象具体性、层级、密度和专业完成度。再核对预期故事，选择或修改候选。可暂时遮住长标题和解释句，判断是否只有文字在承载关系；保留物种、轴、图例、单位及必要科学标签。这是诊断副本，不要求图离开所有文字也能自明。试片和观察都保留，首稿前实质调整也计返工。

工具只保留物理图框、输出可看的对照，不判“主视觉存在”“闭环完整”或美观。配置示例：

```json
{
  "dimensions_mm": [180, 120],
  "items": [
    {"label": "candidate A", "pdf": "candidate-a.pdf",
     "explanation_masks_mm": [[8, 2, 170, 8]]},
    {"label": "candidate B", "pdf": "candidate-b.pdf"}
  ]
}
```

```bash
python3 <skill>/scripts/composition_probe.py studies.json --out composition-review
```

依赖 PyMuPDF，与 scientific-figure 的 PDF 取图工具相同；路径相对配置文件。输入 PDF 必须已是目标尺寸，工具拒绝自动缩放；掩蔽框以毫米、左上原点给出，只遮选定解释句。`native-board.pdf`保留每张图尺寸，`index.html`用于浏览，`inspection.json`始终是 unassessed。可加入同图框的原图裁片 PDF；参考本身不同尺寸时明确准备依据，不静默拉伸。

## 真实试片仍反复同质化时：用参考校准，重置页面布局

只在相同任务已出现反复的主次/整合失败时使用。实际案例中，两张有真实对象的候选调用相同的整宽化学区和设备区，只改下半部；因此“真实候选”仍没有检验最昂贵的空间承诺。先查候选图及其生成方式：是对象还画不好，还是复用的带绝对坐标模块已锁住构图？两者分别处理，不再加一个笼统的“多做候选”要求。

当问题是布局承诺被继承，保留来源提取、对象身份和可复用的局部绘制能力，重新分配整页。先用一张任务接近的实际参考校准：从图面记录入口、主要判断单元、辅助细节的位置与视觉份量，以及哪些对象必须相邻/共享身份。用当前科学内容实际重建一份参考组织的工作基准，再与改变主要比较/阅读组织的方案在原尺寸并排；基准是诊断和学习，不强制最终沿用原图布局。不要只复制配色、圆角和标题，也不要让候选共用未经检验的整宽首行或固定侧栏。已有明确可用布局的局部修改无需重置。

候选选择先看最重要的科学关系由什么视觉组织承担，再看必要对象是否具体且完整：面积、对齐、邻接、重复身份、共享尺度或短路径能否组织理解？文字和箭头可以必要，但仅让所有内容“连接起来”不是整页整合。对象若只能画成主题框，返回来源/局部表示层；对象清楚而全图割裂时，返回分组与视觉份量，避免用更多说明和长线修补。复用绘图代码时，将数据/对象绘制与页面位置分开，不能让旧的绝对布局决定新叙事。

这是针对已观察失败的条件化制作策略，不是所有任务的额外关卡。保留工作基准、真正不同的候选、实际选择观察和被淘汰的方案；原尺寸对照仍用现有 composition_probe。工作基准若已是完整成品，按first-complete规则保存，不能通过改称“试片”隐藏返工。该步骤本身不产生审美通过，最终仍须整图独立对照。

选定后延续同一对象身份和阅读路径制作整图，不把试片当作一次性作业。增加新面板/素材时重新看核心判断是否仍在图内完成；“多了真实对象”不能替代关系整合。字号、色彩、粗斜体和材质服务于这条读者路径；有关实际结构与局部渲染的做法仍见[制作循环](visual-production-cycle.md)，不复制本篇的空间分区作为通用模板。

## 首稿与自主锁定稿不能混名

第一次形成本次请求的完整成品时保存first-complete；之后制作代理可实际查看并自修，记下实质修改，再锁定autonomous提交。首稿本来就有局部瑕疵时仍原样保留，不将已返工稿追称首稿。保存生成源、源身份和实际输出，使差异可定位。

独立试验的主代理只提供材料、模糊想法、规格、环境与冻结方法，不给目标故事、布局、提取好的结论数值或成图改法。技术环境帮助记录在assistance ledger；改文案、数据选择、视角或布局均是内容救场。收到反馈后由原制作代理自行决定修法，留新目录。冻结包不改。

## 盲读先落盘，再看作者解释

评阅者先只看目标尺寸成图、正常图注和整套slide渲染；不看story、自评、代码或旧评语。分别写下第一眼主角、读出的一句话、可见对照、无法辨认的必要信息；再判断TOC、Fig1与报告是否讲同一件事。完整deck逐页看，不以缩略图联系表代替数据/机制页阅读；也要检查跨页节奏和是否反复重复。

先把上述盲读观察保存，再开放全文/SI和共享story进行支持核查。原图提供专业密度、材质和层级参照，不强制新叙事复制原图拓扑。原作者历史印刷尺寸未知时明确未知。

## 盲读之后还要对照原始目标

盲读负责暴露读者实际得到的故事，不单独决定交付完成。盲读记录封存后，向评审提供用户原始交付目标、参考图及可追溯的必要表达任务。评审逐项对照完整成图，不只复查上一轮报错位置；这不会回写先前盲读。用户要求参考级质量时，必须实际观察参照并说明具体差距，不能由作者事后选择的“概念型/教学型”范围代替。`issue_resolution` 与 `overall_delivery` 分别记录；前者全关闭而后者仍不满足是正常结果。判断允许新布局或更清楚的表达，不把复刻原图外观设为默认目标。

## 三种结论，不用“候选”吸收缺陷

- **ready_in_scope**：起稿前用户目标所限定任务的故事、主次、审美、必要细节均有实际图面证据；没有已知实质缺陷。只对当前版本和用途有效，不等于发表批准。
- **revise**：任一核心维度需要实质改动。故事可读但科学主角弱、公式或反应身份难读、视觉等重、过密、重要结构遮挡、图像明显像未完成草稿，都属于此项；不以“没有数值错误”降成可选建议。
- **not_reviewed**：未按要求看目标输出，或信息不足以判断。不能并入ready。

审美意见说明具体对象、版面位置、读者影响及对照依据；“丑/单调”不是充分定位，但不能因审美难量化就不评价。风格偏好和影响阅读的缺陷分开；真正无实质缺陷时可ready，不为显示严格而强行找错。小型局部检查不升级为整稿通过。同一组三图分开结案：数据图的主次改善不能抵消TOC或概览图的未完成。若用户否定已给出的ready，保留旧判断并追加反证，重开被否定的质量维度；不将问题改称风格偏好后继续沿用通过结论。

每项缺陷记录稳定ID、位置、观察、影响、blocking/nonblocking、open/resolved。制作修复后的resolved需要新版本实际观察；不因作者说“改了”就关闭。若核源证明原评语错误，应保留原观察并明确撤回、列出反证，不要求作者改正确内容，也不将撤回计为制作返工。结构化记录可用resolved配resolution_kind=reviewer_retracted区分这一关闭原因。已有`research.py record-review`可加`visual_gate`（模板见assets/visual-review-template.json）：程序只拒绝“passed却仍声明未检查或有阻断”的矛盾记录，不决定美观。没有此字段的旧记录保持兼容，不能当作采用新标准的证据。

## 返工怎样计

从第一次方案开始保留修改记录，分为first-complete之前、自主修改、外部反馈三个阶段；新建初始方案与修改已有方案分开。包括试讲后改叙事、候选试页重排、重要图例／结构边界重裁，不能因发生在首稿前就不算返工。以读者任务为单位记录：story（主张／对照／科学条件改变）、structure（面板／页面结构改变）、visual（主次／字级／视角／注释归属改变）、local（不改变前述内容的局部修饰）、technical（环境／执行修复）。前3项为实质返工；同一问题多次修改保留轮次，不按移动像素拆数。记录修改前后材料、触发观察、受影响页、谁提出和谁改。缺少旧案例早期记录时明确不可同口径比较，不用自主修改轮数下降代替总成本下降。

报告首份完整稿、自主锁定稿、反馈后稿的分项结论与实质返工，不求平均分抵消短板。独立试验可先安排一次完整反馈修订、一次定向复看；若同类失败持续，保留未通过并说明下一决策，不无限修到“成功”。单论文前后试验不能证明方法因果有效，也不能推断所有新论文的成功率。
