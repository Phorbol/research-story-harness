# 写作、图注与修改

## 最小台账与论文计划

只有局部语言修改时，保留事实、限定条件、引用和主张强度即可。论文级任务按需维护下表，已有项目中的等价结构可以直接复用：

| 字段 | 内容 |
|---|---|
| reader_question | 本段/本节读者需要解决的问题 |
| claim_id、text、status | 主张身份、准确措辞与证据状态 |
| evidence_ids、locator | 数据集/文献身份与页码、图号、记录位置 |
| evidence_role | 支持、反证、对照、验证或边界 |
| scope、limitations、alternatives | 条件、未覆盖范围和未排除解释 |
| figure_ids、section_id | 图件/表格与正文连接 |

结果链可以是“观察 → 比较 → 解释 → 验证 → 边界”，也可以由问题与多种解释组成；不要为结构完整虚构一个验证面板。图与主张多对多。主图承载核心判断，补充材料保留必要的复现细节、稳健性和次要比较，不能把反证藏入补充材料。

## 各部分的论证职责

- Introduction：问题、已有证据、具体缺口与本研究要回答的问题。核查原始来源，避免凭综述标题推断创新性。
- Results：陈述观察与相应条件、量值和不确定性，再给限于证据的解释。不能从最小能垒直接推出整体选择性。
- Methods：如实描述样本、排除、对照、分析版本、统计定义、结构与计算条件。未知方法不补写成已经实施。
- Discussion：解释与替代解释、证据强弱、适用边界及下一步可区分的实验/计算。相关与因果分开。
- Abstract/title：覆盖已成立的主问题、方法、结果与有限贡献；起草后回查台账，不能比正文结论更强。

## 图注

按需要交代对象、面板映射、条件、单位与参照态、样本 n 及其独立性、误差条定义、颜色/线型、检验及调整、来源与示意性质。写明“数据表明/支持/与……一致”的范围。图注补足解释，不用隐藏的图注修复本身误导的坐标或关系。

## 修改与审稿回复

先定位影响：措辞/呈现、解释、数据/分析。修改证据后联查相关主张、图件、图注、摘要、正文数值及补充材料；仅修标签不全篇改写。保留未改变的已接受条件和先前修正。

逐条回复审稿人：问题 → 已实施的修改或有证据的异议 → 位置与依据 → 剩余限制。拟做的工作不能写成已完成；没有新增实验时直说基于现有数据重分析或缩小结论。投稿、联系作者及发送回复另遵循实际授权边界。
